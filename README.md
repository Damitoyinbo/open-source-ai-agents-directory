## Agent Frameworks & Orchestration

General-purpose frameworks for building, orchestrating, and running multi-agent systems.

| Project | Description | Link |
|---|---|---|
| CrewAI | Framework for orchestrating role-playing, autonomous agents that collaborate as a "crew" on complex tasks. | [crewAIInc/crewAI](https://github.com/crewAIInc/crewAI) |
| LangGraph | Low-level orchestration library from the LangChain team for building stateful, multi-agent workflows as graphs. | [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph) |
| AutoGen | Microsoft's framework for building multi-agent conversational AI applications. | [microsoft/autogen](https://github.com/microsoft/autogen) |
| AutoGPT | One of the original autonomous-agent projects; lets you build, deploy, and run continuous AI agent workflows. | [Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) |
| MetaGPT | Multi-agent framework that assigns different roles (PM, architect, engineer) to GPT agents to simulate a software company. | [geekan/MetaGPT](https://github.com/geekan/MetaGPT) |
